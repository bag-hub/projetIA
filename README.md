Ce projet est relative à l'énoncé posé par le responsable du cours de "INTRODUCTION A L'INTELLIGENCE ARTIFICIELLE.

La particularité qu'on a eu a observer est que pour une classification avec un jeu de donnée tiré du dataset de CIFAR-10, le travail est d'autant plus structurant qu'instructif, On a explorer donc les différentes facon d'entrainement et de test d'un jeu de donné de millier d'information. Egalement, on plus mis l'accent sur l'optimisation des Classification afin de pouvoir rendre nos resultats un peu plus général sur les 5 classes Choisie.

Exécution Consigne : Pour exécuter notre projet, veuillez etre dans un environnement de travail relative à Jupyter lab, afin de lancer l'exécution de notre notebook (Tout en s'assurant d'avoir mis le kernel d'exécution sur un "PYTHON"). Comme indication notre kernel tourne sur la version 3.14.2 , tout version antérieur au 3, ne fonctionnera pas.

Affichage Consigne : Comme relative à une NoteBook Jupyter, l'affichage se fera en bas de chaque phase d'une seance precise. Les Seances ont été decouper en phase en vue de rendre notre travail comprehensible.... 

Consigne de Séparation de Phase : Je tiens à preciser que le travail demander à chaque seance dans l'énoncé à été découpé en phase apres avoir terminer le code , histoire de le rendre moins dense, plus expressif et compréhensif du point de vue format.
